# Ganesh Shukla — Personal Portfolio Website

## Overview

A modern and responsive personal portfolio website developed to showcase my professional profile, technical skills, capabilities, projects, achievements, education, and contact information. The portfolio focuses on delivering a clean developer-focused experience through smooth animations, responsive layouts, and interactive UI elements.

## Features

- Responsive and mobile-friendly design for seamless cross-device compatibility
- Interactive animations and smooth scrolling effects using GSAP
- Dedicated sections for About, Skills, Capabilities, Projects, Achievements, Education, and Contact
- Interactive Let's Connect modal for quick access to professional links
- Project showcase with relevant technical information
- LeetCode achievement with 50+ days streak
- Clean and reusable frontend code structure
- Professional profile and resume presentation

## Technologies Used

- **React.js** — Component-based frontend development
- **JavaScript (ES6+)** — Interactive functionality and application logic
- **Tailwind CSS** — Utility-first styling and responsive design
- **GSAP** — Advanced animations and scroll effects
- **Vite** — Fast frontend development and build tooling

## Key Highlights

- Designed and developed a visually focused developer portfolio
- Implemented smooth navigation and interactive user experiences
- Optimized the layout for desktop, tablet, and mobile devices
- Added animated interactions to make the portfolio more engaging
- Organized technical skills and capabilities in a clear professional format
- Integrated direct links for GitHub, LinkedIn, Email, and LeetCode
- Added a dedicated Let's Connect panel for professional networking
